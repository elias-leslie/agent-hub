**Result (2026-09-23): Jev made 14 real, successful `jev-1.13.0` calls across all six use cases.** Twelve were frozen initial/perturbation packets and two were focused corrections retained separately. The calls used 44,423 input and 2,108 output tokens, with $0.001865766 of locally calculated API cost and 4.195 seconds summed HTTP time. The complete [typed responses and per-call receipts](live-results-v1.json), [frozen first packets](live-packets-v1.json), [first reference outcomes](live-reference-v1.json), [correction packets](live-packets-v2.json), and [correction reference](live-reference-v2.json) are retained. TypeSafe's [current model contract](https://docs.typesafe.ai/models) prices input at $0.042 per million tokens, output free, with a 64k-token request limit. Account balance and subscription usage were not exposed. No Neri pilot dispatch was used: its ledger remained at 242 rows, $0.071314950 spent, and $0.005376 reserved before and after.

The previous [baseline-only results](results-v1.json) established local workflows and integration risks but **did not test Jev**; their no-Jev recommendations are superseded by this report. A live model choice is evidence of a judgment, not evidence that completed work improved. The first-pass budget classification disagreement is also not a clean Jev failure: our packet omitted the called transport body, and our first rubric overlapped “partial” with “contradicted.” Astra independently found both defects. The correction added complete relevant code and disjoint counterexample precedence; Jev then selected `contradicted`. This is a corrected repeat, not fresh validation.

The agent-controlled input risk is real. The live Neri endpoint's dry run accepted a nonexistent source ID and worker-authored source/rubric hashes without resolving them. For these local calls, [the preparation script](prepare_live_jev.py) assembled source text and whole-file hashes before inference, [the runner](run_live_jev.py) rechecked those hashes and model windows, and the reference answers were committed before the calls. That does not make the evaluator independent of this worker or prove packet completeness—the omitted transport body was caught only by review. These are frozen, predeclared packets, but not a new blind held-out cohort. A source-instruction fixture, persuasive narration, skill order/description changes, and a leading routing summary did not change the tested decisions; the order swap changed search position as expected. Exact receipt replay created zero new provider calls; changed evidence/rubric used new IDs and two new calls. Mocked timeout, unavailable-model, and malformed-response probes remained `not_evaluated`; all live provider calls succeeded, so live outage handling is untested. The runner supplied a bounded HTTP client because the reusable provider helper defaults to `timeout=None`, and it never retries an uncertain call.
